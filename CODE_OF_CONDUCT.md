# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussion about the work, and do not harass anyone.
Report unacceptable behaviour privately through the repository's security contact
(https://github.com/Blicae/wake-grokbot/security/advisories/new). Maintainers may remove comments, commits
or contributors that break these rules.
